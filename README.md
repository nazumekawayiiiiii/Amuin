# Amuin 阿穆英


> **AI 赋能的求职助手，劳动人民找工作也要AI赋能”！**

Amuin 是一款基于 AI 驱动的自动化职位筛选与沟通辅助工具。它能根据你量身定制的个人画像和偏好，自动在招聘平台上为你评估岗位匹配度，过滤掉不合适的机会，让你把精力留给真正有价值的面试。

## 📖 使用指南

⚠️ **重要前提**：Amuin 并非在后台静默运行的“守护程序（Daemon）”。它需要你**手动点击启动**，并且支持在运行过程中**随时暂停或完全停止**，主动权完全掌握在你手里。

### ⚙️ 核心配置项

为了让 AI 懂你，你需要进行一些基础配置。

* **🤖 LLM 配置（必填项）**
    这是 Amuin 的“大脑”。你必须配置好大语言模型（LLM）的 API Key 和相关参数，程序才能具备阅读和分析 JD（职位描述）的能力。
* **🎯 筛选遍历参数（可选项）**
    在这里设定你的硬性指标（比如薪资范围、城市等）。如果你不填任何内容，程序将默认不添加基础筛选条件，直接遍历所有岗位。



### 🧠 个性化 AI 知识库 (高度定制)

<img width="1307" height="875" alt="Screenshot 2026-03-11 105315" src="https://github.com/user-attachments/assets/76308ddf-73fb-494c-870a-0a28c11dea5e" />

让 Aumin 变成你的专属职业经纪人！

* **📝 个人画像 (简历匹配度核心)**
    建议通过 Markdown 文件详细配置你的个人经历、技术栈和优势（文件路径配置在：`...`）。AI 会仔细阅读你的画像，并以此为基准，对每一个抓取到的岗位进行深度匹配筛选。
* **🎭 性格偏好 (跟进语定制)**
    你是高冷极客风，还是热情阳光型？在这里设置你的性格偏好，AI 会根据你的“人设”自动生成合适的打招呼和跟进话术。
    同时也支持在\config\profile.md中配置自己全部信息和需求偏好、加减分规则等。请尽量避免和GUI的配置重复（重复的情况下profile.md的权重更高哦）
* **🚫 偏好设置与一键 Pass (避雷针)**
    极其好用的“黑名单”功能。你可以直接设置某些公司名称，或者在 JD 中出现的“敏感关键词”（比如：外包、大小周、单休）。一经匹配，直接 Pass！
    > *💡 至于“要求能接受高强度加班”这种模糊表述怎么办？我还没测过具体边界，但你完全可以在【个人画像】文档里着重注明你的态度，AI 在阅读 JD 时会自动帮你进行匹配和过滤。*

### 🛑 自动化与风控限制说明

* **📈 智能评分机制：** Amuin 会自动为你调整岗位的评分标准。分数越高，意味着该岗位与你的匹配度、性价比越高。（*注：AI 只是辅助，请务必亲自甄别岗位的真实性和可靠性，谨防招聘诈骗！*）
* **⏱️ 随机防风控休眠：** 为了尽量模拟真实人类的操作节奏，降低被平台风控的概率，程序在每次组合操作之间，会在你设定的两个数值之间**随机选取一个秒数**进行休息（当然职位比较小众的情况下可以设置短间隔时间）。
